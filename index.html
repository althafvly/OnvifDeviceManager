OnvifDeviceManager

This repository hosts a Flatpak distribution for OnvifDeviceManager. Follow the instructions below to easily install it on your Linux system.

Note: You must have Flatpak installed on your system before running these commands.

Installation

Run the following commands in your terminal:

flatpak remote-add --user --no-gpg-verify --if-not-exists onvifmgr https://althafvly.github.io/OnvifDeviceManager/
flatpak --user install onvifmgr io.github.quedale.onvifmgr

Running the Application

Once installed, you should be able to find the OnvifDeviceManager application in your system's application launcher. Alternatively, you can run it via the terminal:

flatpak run io.github.quedale.onvifmgr
